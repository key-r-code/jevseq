Metagenomics / Reference-relative novelty

Can Jev tell when a sequence is unfamiliar?

A controlled study of nucleotide sequences, reference search, and known-versus-unknown decisions. Start small. Measure whether Jev adds value.

InputReference FASTAs + query reads
OutputKnown, unknown, or abstain at a defined rank
Current statusPlanning only. No experimental results.
01 / The question

Unknown relative to our database.

A query is unknown at a rank when its source taxon at that rank has no representative in the frozen reference collection.

A new species can belong to a known family. A weak match or an uncertain answer does not prove novelty.

The main comparison

Does Jev reduce false acceptance of unknown reads beyond what we can achieve with the same search evidence and a conventional decision method?

A positive result is a hypothesis

04 / Biological ground truth

Split taxa first. Simulate reads second.

REFERENCE

Represented taxa

Build the searchable database from designated reference genomes.

KNOWN QUERIES

Different genomes, represented groups

Use separate genomes within represented taxa to test generalization.

UNKNOWN QUERIES

Wholly excluded groups

Simulate reads from taxa missing from the reference collection at the selected rank.

Use InSilicoSeq with recorded seeds and error profiles. Keep development, calibration, and final-test source genomes separate. Family-level novelty is a proposed starting point.

Both known and unknown queries belong in evaluation. Keep query provenance out of Jev's input. Reference-genome queries form a separate, easier condition.

05 / What counts as progress

Evaluate the decision

  • False acceptance of unknowns at fixed known-read retention
  • Novelty AUROC and AUPRC, with class prevalence
  • Calibration and performance with abstention
  • Uncertainty across genomes or clades

Evaluate the whole workflow

  • Search plus API runtime and cost
  • Failures, no-hit cases, and evidence truncation
  • Reverse complements and candidate-order controls
  • Transfer across clades and read conditions

More reads labeled known is not evidence of better classification. Choose the operating target, useful effect size, and budget before final testing.

07 / Decisions to refine

Keep the open questions visible.

Does Jev contribute anything beyond the search?

This is the central uncertainty. Compare against threshold rules and a fitted model. Give each method compatible evidence and disclose feature differences. A null result is a valid reason to stop scaling.

Can we supply the full database or train Jev?

Current request limits rule out whole reference collections in one input, and the service does not offer customer weight adaptation. Success with a small prompt would justify testing reference retrieval, not establish genome-scale capability.

Which settings still need a decision?

Genome subset, taxonomy snapshot, novelty rank, read profile, sample size, search filters, evidence budget, question templates, known-retention target, effect size, and API budget.

What can we claim about pretraining and real data?

Jev's training corpus is unknown, so we cannot verify unseen-genome status for the hosted model. Real metagenomes lack per-read novelty ground truth unless we establish it independently. Report these limits in any publication.
